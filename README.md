# Heart Disease Classification

## Overview
An end-to-end machine learning project exploring heart disease classification using Python and Scikit-learn.

## Objectives
- Explore and visualize the dataset.
- Train and compare classification models.
- Evaluate model performance using appropriate classification metrics.
- Investigate model selection and hyperparameter tuning.

## Technologies
- Python
- NumPy and Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Structure
- `end-to-end-heart-disease-classification.ipynb` — exploratory analysis, model training and evaluation.

## Limitations
This project is for educational purposes only. Its predictions are not medical advice and should not be used to diagnose disease.
